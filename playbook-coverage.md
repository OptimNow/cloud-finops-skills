# Waste-playbook coverage matrix

Generated by `scripts/playbook-coverage.sh` from the playbook frontmatter -
do not edit by hand. CI (`--check`) fails when this file drifts from the
playbooks, so every coverage change shows up in a PR diff.

A zero cell is a coverage gap, not missing data: either a playbook to write
or a gap deferred knowingly. The prioritised backlog lives in
[docs/ROADMAP.md](docs/ROADMAP.md) and is weighted by expected recoverable
spend, not by cell count.

The GPU and SageMaker playbooks are filed by waste mechanism (idle,
overprovisioned, modernization), so the ai-ml-inefficiency row counts only
the token and agent playbooks and understates AI coverage.
